INDOCHINA QUESTION MACHINE — PWA v1.0

Upload ALL files in this ZIP to the root of a NEW GitHub repository and enable GitHub Pages (main branch / root). Open the HTTPS Pages URL to install on Windows, iPhone or Android. For offline use, first load the hosted app while online and allow the service worker to cache the files. The app can also run via a local HTTP server.

Generate random uses weighted section selection: Survey A 10%, Focus B 20%, C 45%, D 25%. Preferences button respects chosen sections and question family. The bank contains approved/reviewed practice questions and rule-based historically validated template questions. No official NESA examination questions have been imported or falsely labelled.

Shake detection depends on device support and permissions. All content is stored on-device; no server or account.

Existing Russia apps are not modified.

Version 1.2: Detailed syllabus filtering. Generate from preferences supports 15 individual syllabus dot points and six key features, as well as sections and question families. Multiple selected dot points or features are OR within each group; dot point and feature groups combine with AND. Unrestricted random ignores these filters. If nothing matches, a clear message is shown rather than silently ignoring selections. Existing saved preferences are preserved.

Version 1.3: Relationship-graph engine with explicit factor-to-outcome relationships, bounded factor comparisons, change/continuity and effectiveness questions. Existing 522 constrained questions retained as fallback. Graph questions prioritised in normal generation. No arbitrary cross-topic mixing. Full app's generated collection includes relationship questions.
